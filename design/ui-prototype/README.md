# Prototipo UI

Prototipo interactivo del dashboard y de la app móvil, generado en Figma Make.
Es la referencia visual de `web/`; la sección "App Móvil" (`MobileScreen` en `src/app/App.tsx`) es la base para la futura app del conductor.

Diseño original: https://www.figma.com/design/M8XEqEA8RX3mH8ZQaTjccH/DriverSafe-IoT-UX-UI-Design

```bash
npm install
npm run dev
```
